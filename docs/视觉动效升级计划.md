## 2. 设计原则

1. **动效表达关系，不做装饰。** 每个动效都要回答一个问题：东西从哪来、到哪去、哪个被选中了。不加循环的装饰动画。
2. **只动 `transform` 和 `opacity`。** 沿用项目规则。模糊值本身不做动画，模糊层的出现靠父元素的 `opacity`。
3. **时长不超过 300ms。** 沿用项目规则。用「轻微回弹」的缓动制造质感，不靠拉长时间。
4. **模糊只放在浮层上。** 弹出菜单、对话框遮罩、命令面板、提示卡片、拖拽遮罩、标题栏。滚动容器（文件列表、Diff、提交列表）一律不加模糊，避免滚动时持续重绘。
5. **玻璃上的文字照样要 4.5:1。** 半透明底的对比度随背后内容变化，按最坏情况（背后是纯白或纯黑）验证。
6. **可以关掉。** 跟随系统「减少动画」和「减少透明度」，设置页再给一个「减少视觉效果」开关。

与全局通用规则的冲突说明：`~/.claude/rules/website-skill.md` 默认禁止毛玻璃，除非明确要求。本次是你明确要求的模糊效果，按本计划执行；但仍遵守其中「模糊只用于固定层」的限制。

## 4. 实施阶段

### V1 动效与玻璃令牌

`tokens.css` 新增，浅色、深色、跟随系统三套都要有：

```css
/* 缓动：进入用轻微回弹，离开用快速收尾，位移类用标准减速 */
--ease-out-back: cubic-bezier(0.34, 1.2, 0.64, 1);
--ease-in-quick: cubic-bezier(0.4, 0, 1, 1);
--ease-emphasized: cubic-bezier(0.2, 0, 0, 1);

--duration-instant: 100ms;  /* 按下反馈 */
--duration-fast: 150ms;     /* 悬停、离开 */
--duration-base: 220ms;     /* 浮层进入、选中位移 */
--duration-slow: 300ms;     /* 视图切换 */
--stagger-step: 24ms;       /* 列表依次出现的间隔，最多作用于前 8 项 */

/* 玻璃层：底色半透明 + 模糊 + 轻度饱和，边缘一圈高光 */
--glass-bg: color-mix(in srgb, var(--color-bg-surface) 72%, transparent);
--glass-bg-strong: color-mix(in srgb, var(--color-bg-surface) 86%, transparent);
--glass-border: color-mix(in srgb, var(--color-border-highlight) 70%, transparent);
--blur-sm: 8px;
--blur-md: 16px;
--blur-lg: 28px;
--glass-filter: blur(var(--blur-md)) saturate(160%);
```

- `ui.css` 新增 `.ui-glass` 工具类。用 `@supports not (backdrop-filter: blur(1px))` 回退到 `--color-bg-surface` 实底。
- `prefers-reduced-transparency: reduce` 时，玻璃层全部回退成实底。
- 验收：对比度脚本覆盖「玻璃底 + 背后纯白」和「玻璃底 + 背后纯黑」两种最坏情况，正文不低于 4.5:1；不达标就提高 `--glass-bg` 的不透明度。

### V2 浮层：模糊 + 完整进出动画

| 浮层 | 改法 | 进入 | 离开 |
|---|---|---|---|
| 分支菜单、推送菜单 | 改用 react-aria 的 `Popover` + `Menu`，自动拿到 `data-entering` / `data-exiting`，同时补上键盘方向键导航 | 从触发按钮方向位移 6px + 缩放 0.97 到 1 + 淡入，220ms | 淡出 + 缩放到 0.98，150ms |
| 命令面板 | 改用 `ModalOverlay` + `Modal`，复用 `ConfirmDialog` 的进出机制 | 遮罩淡入；面板从上方 8px 下落并缩放到 1 | 反向，150ms |
| 确认对话框 | 已有进出动画，只换成新令牌并加遮罩模糊 | 不变 | 不变 |
| 提示卡片 | 新增「离开中」状态，播放完再从队列移除；新卡片进入时，已有卡片用 `transform` 向上让位 | 右侧滑入 16px | 向右滑出并淡出 |
| 拖拽遮罩 | 遮罩模糊背景，卡片轻微放大呼吸一次（只播一次，不循环） | 淡入 | 淡出 |

模糊用量：遮罩 `--blur-sm`（背景只做轻微虚化，仍能看出所在位置）；菜单、面板、提示卡片 `--blur-md` + `--glass-bg`；标题栏 `--blur-lg` + `--glass-bg-strong`，为 D1 的窗口材质预留。

验收：每个浮层快速连续开关 10 次，没有残影或卡住的半透明层；离开动画结束后 DOM 里没有残留节点。

### V3 选中态与列表

- **滑动选中指示条。** 仓库列表、文件列表、提交列表、命令面板的选中背景改成一个独立的指示层，切换选中项时用 `translateY` 滑过去，而不是原地闪烁。行高固定的列表直接用行号算位移；行高不固定的提交列表用 `getBoundingClientRect` 测量。
- **列表依次出现。** 切换仓库、首次加载历史时，前 8 项按 `--stagger-step` 依次淡入并上移 4px；第 9 项之后不做动画，避免长列表拖慢。
- **暂存、取消暂存。** 文件在「更改」和「暂存的更改」之间移动时用 View Transitions，让文件行从原位置平滑移到新分组，而不是凭空消失再出现。浏览器不支持时直接切换。
- 验收：200 个文件的仓库里快速上下切换选中项，性能面板里没有超过 16ms 的长任务。

### V4 微交互

| 元素 | 效果 |
|---|---|
| 所有按钮 | 按下缩放 0.97（100ms），松开回到 1；主按钮悬停时高光从上方扫过一次 |
| 图标按钮 | 悬停时图标上移 1px；刷新按钮点击时整圈旋转一次再停止，而不是只在加载时转 |
| 分段切换 | 滑块换成新缓动，切换时选中文字颜色同步过渡 |
| 复选框 | 勾选时对勾按线条绘制出现（`stroke-dashoffset`，例外说明见第 5 节） |
| 文件行操作按钮 | 悬停时从右侧 4px 位移淡入，不再直接显示 |
| 提交成功 | 提交按钮短暂变成对勾状态 600ms 后复原（状态停留，动画本身仍是 200ms） |
| 拖拽手柄 | 悬停时握把变长，拖动中整条高亮 |

### V5 加载与进度

- **骨架屏。** 文件列表、提交列表、Diff 首次加载时显示骨架行。光带扫过用 `transform: translateX`，不动 `background-position`。只有加载超过 200ms 才显示骨架，避免快速加载时闪一下。
- **远端进度条。** 在获取 / 拉取 / 推送按钮组底部加一条 2px 进度条，宽度用 `transform: scaleX(progress)` 驱动，数据直接用 A2 已有的 `remoteProgress`。
- **视图切换。** 更改与历史互切用 View Transitions 交叉淡化，并带 8px 方向位移（切到历史从右进，切回更改从左进）。

### V6 窗口级材质（原型，取决于 D1）

- Windows 11 开启 `backgroundMaterial: 'acrylic'`，页面底色 `--color-bg-base` 改成半透明，让桌面隐约透出。
- Windows 10 及以下、macOS 检测后回退到当前实底，macOS 可另行评估 `vibrancy`。
- 需要先做原型确认的风险：`frame: false` 下材质是否正常；窗口拖动和缩放时有没有闪烁；深色模式下透出的桌面是否影响对比度。
- 这一阶段失败可以单独回退，不影响 V1 到 V5。

## 5. 规则例外与风险

| 项 | 说明 |
|---|---|
| 加载转圈用 `linear` | 项目规则禁用 `linear`，但持续旋转只能用匀速，否则看起来像卡顿。这是唯一保留的例外 |
| 复选框对勾绘制用 `stroke-dashoffset` | 不属于 `transform` / `opacity`，但它只作用于 16px 的 SVG，不触发布局，开销可以忽略。如果你希望严格执行规则，就改成淡入 + 缩放 |
| 模糊的性能 | 模糊层的开销和覆盖面积成正比。命令面板和对话框遮罩是全屏的，只在打开时存在，可以接受；标题栏常驻，用 `--blur-lg` 前要实测拖动窗口时的帧率 |
| View Transitions | Chromium 111 起支持同文档视图过渡，Electron 33 满足。实现时用特性检测包一层，不支持时直接切换 |
| 包体 | 按 D2 选 B 不新增依赖；选 A 需要锁定 `motion` 的精确版本 |

## 6. 验收标准

1. typecheck、lint、build 通过。
2. 所有动画只动 `transform` / `opacity`（第 5 节列出的两个例外除外），时长不超过 300ms。
3. 系统开启「减少动画」时没有任何过渡；开启「减少透明度」或打开设置里的「减少视觉效果」时，所有玻璃层回退为实底。
4. 玻璃层上的文字在最坏背景下对比度不低于 4.5:1。
5. 滚动容器上没有 `backdrop-filter`：`grep` 只命中第 4 节 V2 列出的浮层和标题栏。
6. 在 1280×800 窗口里用性能面板录制「打开命令面板、切换视图、滚动文件列表」，没有超过 50ms 的长任务。
7. 浅色和深色各截图一组，每个浮层再录一段进出动画的录屏作为证据。

## 7. 实施顺序

V1 → V2 → V4 → V3 → V5 → V6。

V1 是其他阶段的基础。V2 最能直接体现「模糊」和「精致感」，排在第二。V4 改动小、见效快。V3 和 V5 涉及测量和 View Transitions，风险稍高，放后面。V6 是原型，最后做。
