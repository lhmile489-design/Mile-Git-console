# 踩坑记录 · Git-Management-electron

## 2026-11-01 · 项目级复查修复

### 1. `npm run typecheck` 是空跑

- 现象：脚本一直是 exit 0，但单独跑 `tsc -p tsconfig.web.json` 会报 2 个错误。
- 根因：根 `tsconfig.json` 是 `files: []` + `references`，`tsc --noEmit` 不跟 references，等于没检查任何文件。
- 处理：脚本改成分别 `-p tsconfig.node.json` 和 `-p tsconfig.web.json`。改完用故意写错的文件验证会 exit 2。
- 教训：任何「跑起来没输出」的检查命令，都要故意造一个错误验证它真的会失败。

### 2. `git show --numstat` 让中文路径和重命名解析错位

- 现象：历史视图里中文文件名变成 `"\344\270\255\346\226\207.txt"`；重命名文件状态显示为修改；点开文件 diff 是空的。
- 根因：`core.quotePath` 默认开启，非 ASCII 路径被八进制转义；`--numstat` 对重命名输出的是 `old => new` 一段文本，跟 `--name-status` 按新路径建的 key 对不上，拼出来的路径再当 pathspec 用就匹配不到任何文件。
- 处理：`--name-status` / `--numstat` 都加 `-z`，按 NUL 分段解析。`-z` 下路径不转义，重命名格式为 `adds\tdels\t\0old\0new\0`。
- 实测命令：`git show --format= --numstat -z HEAD | od -c`。

### 3. Electron 33 没有 `query-session-end`

- 现象：`tsc -p tsconfig.node.json` 报 `Argument of type '"query-session-end"' is not assignable`。
- 根因：该事件是 Electron 34 才加的，33 的 `electron.d.ts` 里只有 `session-end`。
- 处理：删掉 `query-session-end` 监听，关机 / 注销继续由 `session-end` 兜底。

## 2026-10-28 · 代码审查修复与 UI 重构

### 1. 渲染层类型路径写错，build 照样通过

- 现象：`npm run build` 成功，但 `tsc -p tsconfig.web.json` 报 15 个错误。
- 根因：`src/renderer/src/types/ipc.ts` 重新导出 shared 时多写了一层 `../`。渲染层全部是 `import type`，类型导入会被 Vite 擦除，所以打包不会发现。
- 处理：改成 `../../../shared/types/ipc`。验收时必须单独跑两端 typecheck，不能只看 build。

### 2. `env.d.ts` 里的 `declare module '*.png'` 不生效

- 根因：文件顶部有 `import`，整个文件变成模块，通配模块声明不再是全局声明。
- 处理：图片声明移到不含任何 import/export 的 `src/renderer/assets.d.ts`，并加进 `tsconfig.web.json` 的 include。

### 3. 带正文的提交在历史里丢失作者和日期

- 根因：`git log --format` 里 `%b` 可能有多行，代码按第一个换行切 header，后面的字段被截掉。
- 处理：header 末尾加结束标记 `\x1d`，按标记切分；解析抽成纯函数 `parseCommitLog`。

### 4. 新增 IPC channel 后点击没反应，也没有报错

- 根因：preload 的 `ALLOWED_INVOKE_CHANNELS` 没加这个 channel，返回 9001；调用处用 `void` 吞掉了返回值。
- 处理：新增 channel 时同时改 preload 白名单；调用处不要无条件 `void` 掉结果。

### 5. React Spectrum Provider 会改写字体和高度

- 现象：中英文都显示成宋体；仓库栏只有内容高度，不撑满窗口。
- 根因：Provider 在根节点包一层 div，写死 `font-family: adobe-clean-han, SimSun`，并且没有高度，导致下层所有 `height: 100%` 失效。
- 处理：重构期间用 `#root > div` 临时覆盖；阶段 5 移除 Spectrum 后删除该规则。

### 6. 中文正文 600 字重被渲染成粗体

- 根因：微软雅黑 UI 只有 400 和 700 两个字重，浏览器把 600 落到 Bold。
- 处理：`global.css` 用 `@font-face` + `local()` 定义别名 `Mile CJK`，400 到 600 映射常规体，700 以上映射粗体，放在 `--font-family-ui` 中 Nunito 之后。排查方法：用 CDP `CSS.getPlatformFontsForNode` 看实际渲染的字体，不要凭截图猜。

### 7. 窗口变窄时工具栏图标宽度被压成 0

- 根因：flex 子项默认可收缩，内联 SVG 也跟着被压缩。
- 处理：仓库名、分支名设 `min-width: 0` 并用省略号；分段切换和按钮组设 `flex-shrink: 0`。在 1024×700 下实测元素宽度验证。

### 8. `.selectable` 把正文改成了等宽字体

- 根因：全局 `.selectable` 同时设置了 `user-select: text` 和等宽字体，提交说明加上这个类后变成等宽。
- 处理：`.selectable` 只负责允许选中文字；等宽字体只在 `code`、`pre` 和 diff 区域单独设置。

### 9. 局部 `data-theme="light"` 在深色模式下不生效

- 根因：浅色令牌只写在 `:root` 上，局部元素设 `data-theme="light"` 没有任何选择器命中。
- 处理：浅色令牌的选择器改成 `:root, [data-theme='light']`。设置页的主题缩略预览依赖这一点。

### 10. lucide-react 0.460 的图标名

- `AlertCircle`、`CheckCircle2` 在类型声明里找不到，新名字是 `CircleAlert`、`CircleCheck`。用之前先在 `node_modules/lucide-react/dist/lucide-react.d.ts` 里确认。

### 11. 菜单里打开的确认对话框会被一起卸载

- 处理：`ConfirmDialog` 是受控组件，必须和触发它的菜单做兄弟节点，不能放在菜单内部。

### 12. Playwright 驱动 Electron 做验证

- `app.close()` 后 Electron 进程有时不退出，脚本会被超时杀掉（退出码 124）。脚本结束后要清理残留的 `electron.exe`。
- dev 构建的用户数据目录是 `%APPDATA%\Electron`，与正式版 `Mile Git Management` 分开，验证脚本写入的仓库记录和设置不影响正式版。
- react-aria 的 `ToggleButtonGroup` 单选模式下，按钮的 role 是 `radio`，不是 `button`。
- Node 没有 Python 的 `-I` 参数，运行临时脚本直接 `node script.cjs`。
